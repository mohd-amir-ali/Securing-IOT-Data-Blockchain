SECURING IOT CLOUD DATA

I’m Mohd Amir Ali. This platform bridges the space between wireless sensor networks and immutable blockchain ledgers.

Traditional cloud-connected IoT sensor networks rely on a single centralized repository, leaving environmental and medical telemetry vulnerable to tampering. By routing 20 autonomous sensor nodes through a Mobile Database Node (MDN) with SHA-512 cryptographic hashing and an Ethereum Smart Contract (WSNSecurity.sol), every temperature reading is permanently verifiable.

STEP 01 / EDGE SENSING

Wireless Sensor Nodes

Twenty distributed IoT sensor nodes continuously sample ambient temperature readings and transmit raw telemetry to the Mobile Database Node (MDN) gateway.

STEP 02 / SHA-512 DIGEST

Cryptographic Hashing

Each sensor payload is hashed with a 512-bit SHA-512 digest before storage, making any unauthorized modification across the cloud immediately detectable.

STEP 03 / SOLIDITY CONTRACT

Immutable Ledger Storage

The deployed WSNSecurity.sol smart contract records both operator access credentials and sensor hashes on-chain with sub-10ms local commit times.
