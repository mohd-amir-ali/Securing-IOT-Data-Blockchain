SECURING IOT CLOUD DATA

A decentralized cryptographic defense framework engineered to protect wireless sensor networks against cloud data tampering.

Conventional IoT sensor deployments forward environmental and clinical telemetry to a single centralized server, creating a critical single point of failure. This system routes 20 autonomous wireless sensor nodes through a Mobile Database Node (MDN) gateway, sealing every packet with a 512-bit SHA-512 hash and committing it to the on-chain WSNSecurity.sol smart contract.
